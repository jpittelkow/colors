When it shows

Only when autoplay would have played the next video: autoplay is on, the chain isn't used up, and the server didn't say stop. Otherwise the TV goes back to the rows, as now.

The countdown

5 seconds, a ring that empties and a yellow number. At 0 the next video plays as an autoplay step. Waiting here doesn't count as watch time.

Any press stops it

The first key stops it for good and still does its job: OK plays what has focus (Up next to begin with), the arrows move, Back goes to the rows.

His pick starts a new chain

Watch again, Up next pressed by hand, or a card from the row is his own choice, so the "videos in a row" count starts over. Only the countdown adds to it.

Left alone

After a press, 2 minutes with no key goes back to the rows. If time runs out or a parent presses End now, the Stopped screen takes over.

Nothing new on the server

Up next and the row are the list /upnext already sends: allowed videos that fit the time left, same channel first. Playing one is checked again by /play.
